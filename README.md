# MD to Wechat

一个面向微信公众号的本地 Markdown 排版工具。它可以将 Markdown 文档非常顺滑地转化为公众号的格式，包括 MD 文档当中的表格，它也可以转化为公众号中的图片式表格。它可以将表格转换成高清 PNG，标题、段落、列表、引用、链接与图片仍保留为可编辑的富文本。

## 在线使用

无需安装，直接打开在线版：[MD to Wechat](https://hecules8.github.io/md-to-wechat/)

## 使用

```bash
npm install
npm run dev
```

打开终端显示的本地地址，导入 `.md` 文件或直接编辑示例内容，选择表格主题，然后点击“生成高清表格图片”。生成完成后可一键复制至微信公众号，也可以逐张下载 PNG 或一次下载全部图片的 ZIP 压缩包。

## 本地部署

Windows 用户可直接双击 `启动本地服务.bat`。脚本会在需要时安装依赖、生成生产版本、打开浏览器并启动本地服务：

```text
http://127.0.0.1:4173
```

也可以在终端手动运行：

```bash
npm install
npm run build
npm run start
```

关闭启动脚本的命令窗口即可停止服务。服务仅监听本机回环地址，局域网内的其他设备无法访问。

## 当前能力

- Markdown 实时预览与本地文件导入
- 半自动文章图解：让 ChatGPT 先识别临床数据对比、竞品管线、机制机理等难以用文字理解的内容，或手选图解任务。定量图用数据分析／代码绘图，管线图用结构化矩阵，机制图用科学插画；期刊规范用于指导标注和呈现。核对数据或关系清单后出图，再导入 PNG / JPG / WebP（单张不超过 10 MB）
- 不同内容采用不同创作风格：临床数据采用准确、克制的期刊统计图；竞品管线采用分组矩阵与阶段标记；机制机理采用已确认的精细医学插画取向，保留膜、受体、胞内蛋白、细胞核等空间定位，可用柔和光影与轻度立体层次表达结构。机制示例仅作视觉参考，不将其具体分子或通路套用到新文章
- 配图按文章开头或指定内容块之后定位，支持多图、图注、替换、移动及移除；位置对应的原文变化后会提示重新选择
- 配图与表格图片一起预览和复制；无表格文章可直接复制；可下载包含内嵌图片的图文 HTML 离线查看
- GFM 表格识别，其他文章节点不参与截图
- 2× 像素密度 PNG，按列数自动选择表格宽度
- 表格整体始终占满公众号内容宽度；自适应模式按每列文字量分配 100% 内的占比，逐列手动调整时其余列自动补足或让出空间
- PNG 只截取表格本体，不包含外层留白、装饰边框或圆角
- 超过 12 行的长表格自动分页，每页重复表头，避免图片下部截断
- 翡翠绿、冰川蓝、晴空青、雾光紫、月光银、香槟金、玫瑰粉七套纯色配色，整排表头使用统一实色，正文采用同色系浅色条纹；预览与 PNG 同步，表格文字统一为 1.2 倍行距
- 自适应列宽检查表头与所有数据行，按各单元格最长一行的文字宽度分配；最小列占比只约束过窄列
- 多表格批量转换、逐张下载与全部图片 ZIP 一键下载
- 富文本和纯文本双格式剪贴板写入
- 图片生成与公众号复制分开操作，生成后可重复复制
- 复制前把关键排版样式内联，提高公众号粘贴后的稳定性
- 转换失败时保留原表格，不破坏正文

## 浏览器说明

配图流程不调用 API，也不会自动打开或向 ChatGPT 发送文章；“复制 ChatGPT 配图说明”会将全文与风格要求写入剪贴板，由用户自行粘贴到 ChatGPT。原始 Markdown 不写入图片数据。图片保存在当前页面内存中，刷新或关闭前请下载图文 HTML；HTML 用于离线查看，并非可重新导入的项目文件。导入另一篇 Markdown 时会保留图片库并重置插入位置。

建议使用最新版 Chrome 或 Edge。富文本剪贴板通常要求 `localhost` 或 HTTPS 安全环境。微信公众号仍可能根据平台策略处理 `data:` 图片；如果图片没有随全文进入编辑器，请使用工具下方的 PNG 下载按钮，将图片单独插入对应位置。

## 技术来源

整体工作流参考 [doocs/md](https://github.com/doocs/md) 的公众号 Markdown 编辑体验，局部 DOM 成像使用 [html-to-image](https://github.com/bubkoo/html-to-image)。Markdown 解析使用 Marked，输入 HTML 由 DOMPurify 清理。具体许可证见 `LICENSES.md`。
